# Welcome to My First Backend
***

## Task
A web application that provide information (songs, wives, etc.) about Frank Sinatra.

## Description
The data are fetched from the database: `database.js`.
The API endpoints are like follow:
- '/' returns a random Frank Sinatra song.
- '/birth_date' returns the Frank Sinatra birth date.
- '/birth_city' returns the Frank Sinatra birth city.
- '/wives' returns the Frank Sinatra wifes.
- '/picture' returns a Frank Sinatra picture.


## Installation
To install the app, you should use the following commands.
```
npm install
```

## Usage
To start the web app, you should use the following commands.
```
node app.js
```
