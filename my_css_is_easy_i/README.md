# Welcome to My Css Is Easy I
***

## Task
The problem consist to create a responsive page of 04 layouts.
The third layout contains two child layouts and should be wrap in mobile view.

## Description
To solve this problem, i created 03 css classes.
- `container` for the block of parent layouts.
- `row` for the parent layout
- `col` one for the child layout

## Installation
No installation is needed. A web browser is enough.

## Usage
The page can be open with a webbrowser.
