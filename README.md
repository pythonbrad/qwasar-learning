# Welcome to My Spaceship
***

## Task
The task contisted to browse in a map based on a giving set of intructions.
The challenge was to understand the moving in the map.

## Description
To solve the problem, i make the point move and rotate based on the provided set of intructions.

## Installation
There is no installation require.

## Usage
You just need to call the function `my_spaceship` with the path like follow.
```
my_spaceship('LRAAA');
```
