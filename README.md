***

## Task
TODO - What is the problem? And where is the challenge?
The problem is to calculate the Levenshtein number of two givin strings.
The most challenging part is the iteration between the both string.

## Description
TODO - How have you solved the problem?
TO solve this problem, i used a loop to iterate between the two givin strings.
At each iteration, i checked if the both characters at the same index are same.
If not same, i incremented my Levenshtein value.
At the end, i will got the Levenshtein value of the two givin strings.
In case that the two givin strings don't have the same length, i returned -1.
