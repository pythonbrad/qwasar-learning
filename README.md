# Welcome to My Cat
***

## Task
An implementation of the cat command.

## Description
The program take a list of file and print it to the standart output.

## Installation
The gcc compiler is require for compilation.
```
gcc -o hello hello.c
```

## Usage
Run the compiled program.
```
./hello argument1 argument2
```
