# Welcome to Quest06
***

## Task
Implement an iterative function that return the value of a power.

## Description
The function multiply the number by himself n times.

## Installation
No installation is required. You just need to have gcc.

## Usage
```
my_iterative_pow(2, 4); // 16
```
