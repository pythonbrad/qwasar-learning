## Task

The task consisted to learn how to install a package while recording the process.

## Description

To install a package in Ubuntu, we should first update the package list through `sudo apt update`.
After we can search for the desiring kind of package using `apt-cache search <keywords>`.
And finally install it via `sudo apt install <package-name>`.

## Installation

No installation is required.
